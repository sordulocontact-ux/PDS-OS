# Bonnes pratiques

Ce que les retours de Sacha ont appris, pour ne pas refaire la même erreur. Ce dossier servira à
écrire un skill qui les appliquera d'office.

- `retours-design.md` : chaque retour design de Sacha, tel qu'il l'a dit, avec sa capture
  (`captures/`), son explication et ce qui a été fait.
- Une fiche par bonne pratique tirée d'un retour : le geste à faire, pourquoi, d'où elle vient.
  La règle qui en découle entre aussi dans `docs/DESIGN.md`.
