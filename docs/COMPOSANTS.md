# Inventaire des composants

> **Tenu à jour par Claude, sans qu'on le demande.** Dès qu'un composant commun, une
> variante, un token ou une icône est ajouté, modifié ou supprimé, mettre à jour cet
> inventaire **dans la même tâche**. Une ligne par élément, pas de détail d'implémentation.
> Règles visuelles : `docs/DESIGN.md` ; valeurs : `app/globals.css`.

**Sources.** Règles : `docs/DESIGN.md` → valeurs : `app/globals.css` (DESIGN.md d'abord,
puis le CSS). Ton d'un état : `lib/ui/state-tones.ts`, jamais choisi au cas par cas (dont `workStatusTone`,
`deliverableStateTone`, `budgetStatusTone`, `validationTone`, `framingStepTone`, `partyStatusTone`, `projectPriorityTone`, `contractStateTone`, `factTone`, `planItemTone`, `legalFormTone`, `agreementTone`, `templateStatusTone`, `splitVersionTone`, `splitConfirmationTone`, `clearanceTone`, `formalityTone`, `workflowStatusTone`, `dependencyTone`, `audioValidationTone`, `titleDistributionTone`, `splitReviewTone`, `activationStatusTone`, `proofTone`, `measureTone`, `activationSheetTone`, `activationMessageTone`, `severityTone`, `briefRequestTone`, `adminStatusTone`, `collaborationStageTone`, `reviewActivationStatusTone`, `evidenceVerificationTone`, `marketingReportTone`, `marketingReserveTone`, `marketingStatusTone`, `draftConfidenceTone`, `proposalTone`, `strategyReserveTone`, `briefChangeTone`, `contractValueTone`, `sessionStatusTone`, `workStatusFileTone`, `engineerSignalTone`, `distribution*Tone`, `platform*Tone`, `anomaly*Tone`). Teinte d'une catégorie (étape, type de projet, titre d'un projet, projet d'un call au calendrier) : `lib/ui/category-hues.ts` (`stageHue`, `projectTypeHue`, `titleHue`, `projectHue`, `moduleHue` = workflow d'une action du Travail, classes `hueClass`).

**Tokens** (`app/globals.css`) : palette `--po-*` · sélection `--selection`, `--selection-*` (bleu, accent unique : focus, champ, radio, case, carte de choix ; `docs/DESIGN.md` § 3 bis) · teintes de catégorie `--hue-*` (§ 3 ter) · surfaces `--surface-*` (dont `--surface-glass`), `--overlay-*`, flous `--glass-blur` (page) et `--glass-panel-blur` (panneau) · · C0 du 18/10/2026 : `--type-micro` 13 px (`text-micro` : sources, pastilles, libellés de grille d'étape), `--type-display-module` 30 px (`text-display-module`, h1 de module), `--elevation-card` (carte « Maintenant »), `--elevation-modal`, `--glass-scrim`, `--dialog-width(-wide)`, ton `action` gris ; toast sonner noir (`ui/sonner.tsx`)
texte `--text-*` · bordures `--border-*`, `--hairline-*` · tons d'état `--tone-*` ·
contrôles `--control-*` · erreur de saisie `--error` (le seul rouge : champ manquant, message d'erreur ; `--destructive` reste à l'encre) · typo `--type-*`, `--fw-*`, `--font-*` · espacement `--space-*`,
`--stack-*`, `--section-*`, `--page-*` · densité `--density-*` · rayons `--radius-*` ·
