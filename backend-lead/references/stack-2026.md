# Stack 2026 — snapshot des versions, dates et changements récents

Snapshot au **27 septembre 2026**. Tout ce qui est ici bouge : pour une version précise, une
date de fin de support ou une API nouvelle, **fais une recherche web** avant d'affirmer.
Ce fichier te dit _ce qu'il faut vérifier_ et _ce qui a changé récemment_ pour ne pas coder
avec des réflexes de 2024.

## Hébergement (repères)

- **Vercel** : `use cache` géré, Fluid compute, Vercel Queues/Workflow ; CDN consomme
  `stale-while-revalidate`/`stale-if-error`.
- **Fly.io / Railway / Render** : containers, Postgres managé, workers séparés faciles.
- **Cloudflare Workers** + Hono + D1/Hyperdrive : edge ; attention aux limites CPU et aux libs
  Node.
- Self-host (VPS + Docker/Coolify) : viable ; prévois pooler, backups, `use cache: remote`.
